1. Upload and validate

Export CSV UTF-8 from Excel (up to 500 rows, 512 KB) with these columns:

BRANCH_CODE, BRANCH_NAME, LOCATION, PHONE, CHAIR_CODE, CHAIR_NAME, STORE_CODE

Use one row per chair, repeating the same branch details. To import a branch without chairs, leave both chair fields blank.

Branch and chair codes are permanent identifiers (up to 20 letters, numbers, hyphens or underscores). Chair codes are unique within a branch; another branch may use the same chair code. LOCATION is stored as the branch address.

STORE_CODE is the optional Google Business Profile store code (for example HS-001). It must match the review source exactly and be unique across branches. Blank or omitted store codes preserve existing values.

Matching codes update names and supplied branch details. Blank/null location or phone preserves existing values. New rows create active records; inactive records must be reviewed in administration first. Missing rows are never deleted. Staff assignments, rosters, visits and recorded tasks are not rewritten.
